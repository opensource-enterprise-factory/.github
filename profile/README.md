
# Open Source Enterprise Factory (OSEF)

### Build · Deploy · Contribute
**For a Sovereign and Innovative Africa**

Welcome to **Open Source Enterprise Factory (OSEF)**, an emerging open source engineering initiative dedicated to making enterprise-grade open source technologies accessible, reliable, secure, and sustainable for African organizations.
## Our Mission

Bridge the gap between open source innovation and enterprise production through engineering, integration, security, operations, support, and upstream contributions.

## What We Focus On

- **Cloud Native & Kubernetes** — Kubernetes infrastructure, GitOps, Platform Engineering, and SRE.
- **Enterprise Open Source** — Evaluation, integration, hardening, and operationalization of open source solutions.
- **Security & Reliability** — Identity, supply chain security, observability, backup, and resilience.
- **Open Source Contributions** — Documentation, testing, bug fixes, code, and community collaboration.
- **Engineering Talent** — Hands-on labs, mentorship, and practical skill development across Francophone Africa.

## Our Engineering Approach

**Discover → Design → Build → Secure → Deploy → Operate → Support → Contribute**

We believe open source adoption goes beyond installing software. It requires engineering discipline, production readiness, maintainability, and sustainable knowledge transfer.

## Our Contribution Program
OSEF aims to contribute to projects across the cloud native ecosystem, starting with:
- [Kubernetes](https://github.com/kubernetes/kubernetes) and [Kubernetes Website](https://github.com/kubernetes/website)
- [Argo CD](https://github.com/argoproj/argo-cd)
- [OpenTelemetry](https://github.com/open-telemetry)

Our first contribution initiative is **OSEF-001 — Kubernetes SIG Docs**.
Contributions and upstream acceptance will be documented publicly as the program develops.
