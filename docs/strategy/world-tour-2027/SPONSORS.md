## Gouvernance commerciale
- Conserver les données personnelles de contacts dans un CRM autorisé, non dans ce dépôt public.
- Qualifier la compatibilité des contreparties avec les règles des événements.
- Un *engagement verbal* n'est pas un contrat signé ; un contrat signé n'est pas un encaissement.
